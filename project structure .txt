Main technology flow
--------------------
React frontend
    -> Express API in server.ts
    -> Supabase Auth for login sessions and password recovery
    -> Supabase PostgreSQL for database persistence
    -> Google Gemini API for assistant and HSN suggestions

Important database tables
-------------------------
- businesses                         Default business and business ownership records
- customers                          Customer records
- smartbill_business_profiles        Business profile payloads
- smartbill_products                 Product and inventory payloads
- smartbill_invoices                 Invoice and Quick Bill payloads
- smartbill_payments                 Payment payloads
- smartbill_inventory_logs           Inventory movement payloads
- smartbill_audit_logs               Audit history payloads
- smartbill_records                  Legacy generic migration table

Important API areas in server.ts
--------------------------------
- /api/health                       Public health check
- /api/auth/login                   Supabase email/password login
- /api/auth/session                 Current authenticated session
- /api/auth/logout                  Session logout
- /api/auth/forgot-password         Password reset email request
- /api/auth/reset-password          Password update from recovery link
- /api/customers                    Customer CRUD and migration
- /api/products                     Product create/update/delete sync
- /api/invoices                     Invoice persistence
- /api/payments                     Payment persistence
- /api/migrate-local-data           Legacy browser-data migration endpoint
- /api/ai/*                         Gemini assistant and HSN suggestion endpoints

Common commands
---------------
npm install                         Install dependencies
npm run dev                         Start the development server on port 3000
npm run lint                        Run the TypeScript check
npm run build                       Build the frontend and production server
npm start                           Start the production server
npm run clean                       Remove generated build output
